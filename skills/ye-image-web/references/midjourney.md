# Midjourney

入口 [Midjourney](https://www.midjourney.com/)。先看当前模型支持哪些参考类型。

| 参考入口 | 操作要点 |
|---|---|
| Image Prompts | 引导人物、物件或构图。核对图片确实在本轮图像提示区。 |
| Style Reference | 引导风格。需要维持人物身份时，检查当前模型提供的角色或对象参考能力。 |
| Moodboard | 引用一组审美方向。记录实际选择的板与任务回显的引用。 |

**准备任务。** 在 Create/Imagine 确认输入区和旧附件。上传图片并放进对应参考区，检查实际缩略图。核对模型、画幅、情绪板及会影响本轮的全局默认参数。普通图像提示通常会引导重绘，精确局部编辑要先检查对应的编辑能力。

**创建情绪板。** 先找已有板，按任务复用或创建。等上传结束，重新进入板核对图片已经保存。通过当前页面提供的方式取得引用。历史记录可能出现 `--p` 或回显中的 `--profile`，以本轮页面和任务详情为准。

**回查任务。** 在 Organize 或搜索里定位结果，逐张核对候选位置，记录回显参数和参考类型。查看详情优先。使用 Use → Prompt 回读会改输入草稿，先保留现有草稿，并在回读后按原任务范围操作。

**原图与垫图。** 从单张结果的下载入口取原图。查历史垫图时先看任务详情中的 Image Prompt。若详情只显示小预览，可检查页面提供的大图入口或实际出现的参考链接。原图不可得时注明预览尺寸或缺失情况。

历史任务里的参考链接有时是 `s.mj.run` 短链接。只有当前详情实际提供时才沿链接查源图，以能打开的文件及其实测尺寸核对。情绪板的参数和当前模型兼容性可查 [MJ 官方说明](https://docs.midjourney.com/hc/en-us/articles/39193335040013-Moodboards)。
