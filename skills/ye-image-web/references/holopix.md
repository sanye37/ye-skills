# Holopix

入口 [Holopix](https://holopix.cn/)。以用户提供的画布和当前界面为准。

1. 在自由画布确认目标节点。缩放较小时，根据节点位置和缩略图定位，再用「查看详情」核对是哪一轮的结果。编辑已有图时，查看该图是否有「重新编辑」入口，先读它带入的参考、提示词和设置。
2. 普通生成与模板任务分别核对。模板可能提供世界观、对象类型和数量等字段。填写任务自己的值，确认示例图是否进入实际参考区。
3. 上传后逐张核对缩略图和顺序。填词后回读全文。先选模型，再看质量、分辨率和画幅是否被模型或模板重置。以提交面板的参数摘要核对本轮实际选择。
4. 提交后在画布或创作记录里确认新任务。完成后打开结果大图，下载原文件并核对实际尺寸。选择「智能」比例时，以结果文件测得的像素给出实际画幅。
5. 复盘从「查看详情」和创作记录取证。展开完整提示词，记录参考顺序、模型、画质、分辨率、比例和结果。历史列表分页或按滚动加载时，观察是否出现新的任务。重复缩略图先归到所属任务，再核对是否同一参考。

历史观察中的「添加参考图」「删除参考图」「查看详情」可作为定位线索。当前页面有同名控件时，先确认它属于本轮任务。
