# Lovart

入口 [Lovart](https://www.lovart.ai/)。这些步骤来自历史实操，按钮与模型以当前页面为准。

1. 在指定项目核对当前画布选中的图、生成面板里的参考卡片、提示词和参数。要继续改上一轮结果时，确认选中的实际版本已经成为本轮编辑底稿。
2. 从参考区或上传入口加入本轮素材，检查卡片内容和排列。用本轮真实编号写清编辑底稿、各参考的用途及保留范围。
3. 先选模型，再核对质量、画幅和数量。若这些设置集中在一枚摘要按钮上，展开核对各项。选择模型后重新读取摘要。
4. 连续编辑每一步明确父图。例如横版扩展用已选中的竖版成图作为底稿，验证主体保留、画布实际扩展。组合两版优点时，主底稿负责整体，另一张明确只取某个局部。每轮另存结果并记录前后关系。
5. 从目标结果或详情的下载入口取原图。保存生成结果和实际输入记录。权限或登录使详情不可读时，已有下载与线上任务记录分别列出。
