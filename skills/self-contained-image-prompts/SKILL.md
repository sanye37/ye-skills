# agent生图提示词撰写技巧

利用对话理解用户意图；把每次交给生图模型的提示词当作独立任务，只依赖本次实际提供的文字与图片。

## 写作

1. 确认模型本次会收到的图片与文字。将必要的历史要求展开成明确描述；影响结果的关键信息缺失时，先向用户澄清。
2. 用可辨认的对象、画面关系和具体动作表达要求。将内部黑话、流程术语及依赖前文的指代转换成画面语言，保留适用的美术术语。
3. 优先描述希望呈现的结果，仅在必要时使用负向描述。保留用户明确的排除要求，用简短、具体的表达说明。
4. 除知名项目外，将项目风格转换成达到该效果的具体做法，按需描述造型、比例、线条、色彩、光影或材质。对知名项目的风格也只采用与本次目标相关的特征。
5. 有参考图时，按实际输入顺序或可辨认特征逐一对应，明确每张图用于参考哪些内容；区分待编辑图与参考图。仅引用本次会提供给模型的图片。
6. 反复改稿仍偏离目标时，围绕当前认可的设计和本次核心问题重写精简、自足的提示词。用正向描述交代关键形状与关系，删去历次补丁、重复修饰和已失效的限制；检查保留项完整、描述之间相容。

## 交付检查

假设接收者没看过对话：仅凭本次输入，能否辨认对象、理解操作、对应参考图，并知道目标画面？补齐必要信息，删去重复表述和无关历史；文字应精简而完整。

默认直接输出可用提示词，不附写作过程。此 Skill 只负责提示词写作，生成图片须依据用户另行提出的生成请求。
